## 🌟 О проекте (Overview)

**Pentalyze** — это интеллектуальное решение на базе искусственного интеллекта для многомерного анализа, стилистической полировки и 3D-визуализации предложений. Из одной фразы или короткого абзаца система извлекает пять взаимодополняющих уровней анализа.

Система поддерживает 10 основных мировых языков и их оригинальные письменности. Результаты анализа оформляются в виде трехмерной электронной книги в твердом переплете с реалистичной физикой перелистывания страниц, режимом параллельного двуязычного сравнения (Split-View) и многоязычной озвучкой (TTS).

## 🔑 Принцип Работы API и Руководство по Google AI Studio

### 1. Безопасность и модель работы ключей в репозитории
* В исходном коде отсутствуют персональные ключи API разработчика.
* При клонировании и локальном запуске приложения используется безопасная модель **BYOK (Bring Your Own Key — Используйте собственный ключ)**.
* Введенные в браузере ключи сохраняются исключительно в локальном хранилище `localStorage` вашего устройства и никогда не передаются на сторонние серверы.

### 2. Получение бесплатного ключа Google AI Studio (Рекомендуется)
Pentalyze оптимизирован для работы с Gemini API от **Google AI Studio**:
1. Перейдите на сайт [Google AI Studio (https://aistudio.google.com/)](https://aistudio.google.com/) и войдите под своим Google-аккаунтом.
2. В боковом меню нажмите **'Get API key'**.
3. Нажмите **'Create API key'**, создайте проект и скопируйте бесплатный ключ.
4. В Pentalyze нажмите на иконку **Настройки (⚙️)** в правом верхнем углу, выберите **[Использовать собственный API-ключ]**, вставьте ключ Gemini и нажмите **Сохранить**.
   - Либо скопируйте `.env.example` в `.env` в корневой папке и укажите:
     ```env
     VITE_GEMINI_API_KEY=ваш_ключ_google_ai_studio
     ```

### 3. Подключение сторонних моделей (OpenAI, DeepSeek, локальная Ollama)
* **OpenAI (GPT-4o)**: Выберите OpenAI в окне настроек и введите ключ `sk-...`.
* **Локальные модели (Ollama)**: Вы можете указать локальный адрес (например, `http://localhost:11434/v1/chat/completions`) в файле `src/services/ai.ts`.

## 🎯 5 Уровней Анализа ("Gyeol")

1. **Уровень 1: Интерпретация (Interpretation)**: Раскрытие прямого смысла, подтекста, скрытых мотивов и тональности.
2. **Уровень 2: Главная мысль (Summary)**: Лаконичная выжимка ключевой идеи, считываемая за секунду.
3. **Уровень 3: Подробное объяснение (Deep Explanation)**: Анализ словарного состава, терминологии и фонового контекста.
4. **Уровень 4: Грамматика и стилистика (Grammar & Polish)**: Исправление синтаксиса и адаптация текста под строгий деловой стиль.
5. **Уровень 5: Перефразирование (Paraphrasing)**: 3 изящных альтернативных варианта формулировки для разных регистров общения.

## 🚀 Основные Возможности

- **Реалистичная 3D-книга**: Трехмерные CSS-эффекты изгиба страниц, реалистичные тени и управление жестами.
- **Двухуровневая локализация**: Интерфейс приложения остается на вашем родном языке, а текст книги можно переводить на любой из 10 языков.
- **Режим сравнения (Split-View)**: Наглядное сопоставление исходного предложения с отредактированным результатом.
- **Поддержка PWA**: Установка в виде автономного приложения на смартфон, планшет или ПК с поддержкой офлайн-режима.
- **Гибридный аудиоплеер (TTS)**: Стандартный речевой движок браузера и интеграция с клонированием голоса ElevenLabs.
- **Своя библиотека и экспорт**: Автоматическое сохранение анализов и экспорт в Markdown или PDF.
