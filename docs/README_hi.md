## 🌟 परियोजना परिचय (Overview)

**Pentalyze** एक AI-संचालित वाक्य विश्लेषण, संपादन और ३D विज़ुअलाइज़ेशन समाधान है जो किसी एक वाक्य या संक्षिप्त गद्यांश से ५ अलग-अलग भाषाई और संदर्भगत दृष्टिकोण (५ परतें / 5 Gyeol) निकालता है।

यह प्रणाली दुनिया की १० प्रमुख भाषाओं और उनकी मूल लिपियों (यथा: हिन्दी के लिए देवनागरी, कोरियन के लिए हांगुल, रूसी के लिए सिरिलिक, जापानी के लिए कांजी/काना तथा अंग्रेज़ी/स्पैनिश आदि के लिए लैटिन लिपि) का समर्थन करती है। विश्लेषित परिणाम को वास्तविक पन्ने पलटने की अनुभूति देने वाली ३D हार्डकवर पुस्तक, द्विभाषी समानांतर तुलना दृश्य (Split-View) और रीयल-टाइम बहुभाषी ऑडियो (TTS) के साथ प्रस्तुत किया जाता है।

## 🔑 API कार्यप्रणाली एवं Google AI Studio कुंजी एकीकरण मार्गदर्शिका

### 1. सुरक्षा संरचना एवं GitHub क्लोन में 'BYOK' कार्यप्रणाली
* इस रिपॉजिटरी के स्रोत कोड में निर्माता की कोई भी व्यक्तिगत API कुंजी शामिल नहीं है।
* जब कोई उपयोगकर्ता इसे GitHub से क्लोन (डाउनलोड) करके अपने स्थानीय वातावरण (PC/टैबलेट/मोबाइल) में चलाता है, तो यह प्रणाली **BYOK (Bring Your Own Key - अपनी स्वयं की कुंजी लाएं)** मॉडल पर सुरक्षित रूप से कार्य करती है।
* उपयोगकर्ता द्वारा दर्ज की गई API कुंजी केवल उसके ब्राउज़र के `localStorage` में सुरक्षित रहती है और किसी बाहरी सर्वर पर प्रेषित नहीं की जाती।

### 2. Google AI Studio से निःशुल्क API Key प्राप्त करने की विधि (अनुशंसित)
यह एप्लिकेशन **Google AI Studio** के Gemini API के लिए पूर्णतः अनुकूलित है। कोई भी व्यक्ति निःशुल्क कुंजी प्राप्त कर सकता है:
1. [Google AI Studio (https://aistudio.google.com/)](https://aistudio.google.com/) पर जाएं और अपने Google खाते से लॉगिन करें।
2. नेविगेशन मेनू में **'Get API key'** पर क्लिक करें।
3. **'Create API key'** बटन दबाएं, प्रोजेक्ट चुनें और अपनी नई API कुंजी कॉपी करें।
4. Pentalyze ऐप में ऊपर दाईं ओर **सेटिंग्स आइकन (⚙️)** पर क्लिक करें ➔ **[मेरी API कुंजी का उपयोग करें]** चुनें ➔ Gemini कुंजी पेस्ट करें और **सहेजें (Save)** पर क्लिक करें।
   - अथवा रूट फोल्डर में `.env.example` की प्रतिलिपि बनाकर `.env` फ़ाइल बनाएं:
     ```env
     VITE_GEMINI_API_KEY=आपकी_GOOGLE_AI_STUDIO_API_कुंजी
     ```

### 3. अन्य AI मॉडल (OpenAI, DeepSeek, स्थानीय Ollama) का उपयोग
* **OpenAI (GPT-4o)**: सेटिंग्स विंडो में OpenAI चुनें और अपनी `sk-...` कुंजी दर्ज करें।
* **स्थानीय LLM (Ollama)**: `src/services/ai.ts` में जाकर बेस URL (जैसे `http://localhost:11434/v1/chat/completions`) को अपने लोकल सर्वर से जोड़ सकते हैं।

## 🎯 ५ विश्लेषणात्मक आयाम (5 Dimensions of Insights)

1. **प्रथम आयाम: गूढ़ अर्थ एवं व्याख्या (Interpretation)**: प्रत्यक्ष अर्थ के साथ-साथ अंतर्निहित भाव, स्वर और संदर्भ का विश्लेषण।
2. **द्वितीय आयाम: सार संक्षेप (Summary)**: पूरे विचार को मात्र १ सेकंड में समझने योग्य मुख्य संदेश में संक्षिप्त करना।
3. **तृतीय आयाम: विस्तृत व्याख्या (Deep Explanation)**: प्रासंगिक तकनीकी शब्दावली, सांस्कृतिक पृष्ठभूमि और ज्ञान का स्पष्टीकरण।
4. **चतुर्थ आयाम: व्याकरण संशोधन एवं परिष्कार (Grammar & Polish)**: व्याकरण त्रुटियों को सुधारना और औपचारिक व गरिमापूर्ण शैली में पुनः लिखना।
5. **पंचम आयाम: रचनात्मक पुनर्वाक्यीकरण (Paraphrasing)**: विभिन्न अवसरों और औपचारिकताओं के अनुकूल ३ सुरुचिपूर्ण वैकल्पिक अभिव्यक्तियाँ।

## 🚀 मुख्य विशेषताएं (Key Features)

- **सजीव ३D फ्लिप-बुक इंजन**: CSS 3D परिप्रेक्ष्य, प्राकृतिक पन्ना मोड़ और स्पर्श/माउस ड्रैग द्वारा पन्ने पलटने की सुविधा।
- **दोहरी बहुभाषी संरचना**: सिस्टम मेनू को अपनी पसंदीदा भाषा में रखते हुए ३D पुस्तक की सामग्री को किसी भी समर्थित भाषा में AI अनुवाद और वाचन के साथ पढ़ें।
- **द्विभाषी तुलनात्मक दृश्य (Split-View)**: मूल वाक्य और परिष्कृत वाक्य की आमने-सामने तुलना।
- **PWA (प्रोग्रेसिव वेब ऐप)**: बिना ब्राउज़र बार के मोबाइल व डेस्कटॉप पर स्टैंडअलोन ऐप की तरह इंस्टाल करें और ऑफलाइन उपयोग करें।
- **हाइब्रिड ऑडियोबुक (TTS)**: ब्राउज़र का मानक ध्वनि इंजन और ElevenLabs आवाज़ क्लोनिंग का समर्थन।
- **व्यक्तिगत पुस्तकालय एवं निर्यात**: विश्लेषणों का स्वतः स्थानीय भंडारण तथा Markdown या PDF में निर्यात।

## 📦 त्वरित शुरुआत (Quick Start)

### पूर्वापेक्षाएँ (Prerequisites)
- **Node.js** 18.0 या उच्चतर ([आधिकारिक वेबसाइट (nodejs.org)](https://nodejs.org/) से LTS संस्करण स्थापित करें)

---

### 🖱️ सामान्य उपयोगकर्ता: एक क्लिक में चलाएँ (One-Click Launch - अनुशंसित)
रिपॉजिटरी डाउनलोड (ZIP अनपैक) करने के बाद, अपने ऑपरेटिंग सिस्टम के अनुसार फ़ाइल पर डबल-क्लिक करें। यह **निर्भरताओं को स्वचालित रूप से स्थापित करेगा और ब्राउज़र में 3D पुस्तक खोलेगा**:

* **Windows उपयोगकर्ता**: फ़ोल्डर में मौजूद **`start.bat`** पर डबल-क्लिक करें।
* **Mac / Linux उपयोगकर्ता**: टर्मिनल में `bash start.sh` चलाएँ।

---

### 💻 डेवलपर्स: टर्मिनल कमांड द्वारा चलाएँ
```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/your-username/pentalyze.git
cd pentalyze

# निर्भरताएँ स्थापित करें
npm install

# स्थानीय विकास सर्वर प्रारंभ करें (Port 3000)
npm run dev

# उत्पादन संस्करण तैयार करें
npm run build
```
